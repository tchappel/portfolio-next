# React 19: A Deep Dive into the New Hooks

React 19 introduces **server actions** and several new hooks designed to simplify async logic.

```tsx
"use client";
import { useActionState } from "react";

const [state, formAction] = useActionState(submitForm, initialState);
```

These hooks make client–server coordination far more intuitive.
