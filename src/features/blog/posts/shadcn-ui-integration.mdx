# Integrating shadcn/ui with Next.js

After installing with `npx shadcn-ui@latest add button`,  
you can easily extend styles using **class-variance-authority**.

```ts
const button = cva("rounded-xl text-sm", {
  variants: { intent: { primary: "bg-primary text-white" } },
});
```
